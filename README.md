# Fapel Payroll — rilis APK

Repo ini **hanya** berisi rilis APK aplikasi Android Fapel Payroll (klien fapelpayroll.com). Kode sumber ada di repo
privat terpisah.

- Unduh versi terbaru: [Releases → Latest](https://github.com/Fauzanza/fapel-payroll-rilis/releases/latest)
- Tiap rilis berisi `FapelPayroll-<versi>.apk` dan `versi.json`. Aplikasi membaca `versi.json` rilis terbaru untuk
  menawarkan pembaruan, memeriksa SHA-256 unduhan, lalu membuka pemasang Android.
- APK ditandatangani kunci rilis Fapel Payroll (sertifikat SHA-256
  `91ea607e7a34e593fb20e3278657b2c623cad1092a62254e64cb75a47c09da93`). Jangan pasang APK dengan sertifikat lain.

Pemasangan pertama: unduh APK di HP, izinkan "Instal aplikasi tidak dikenal" untuk browser/berkas, lalu pasang.
Pembaruan berikutnya cukup dari dalam aplikasi.
